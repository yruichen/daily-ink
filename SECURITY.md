# Security Policy

## Supported Versions

Daily Ink is currently in early development. Security fixes are applied to the
latest code on `main`; older commits and unreleased forks are not supported.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** form in the repository Security tab:

<https://github.com/yruichen/daily-ink/security/advisories/new>

Include the affected version or commit, reproduction steps, expected impact,
and any suggested mitigation. Remove API keys, journal entries, model outputs,
and other personal data from the report.

You should receive an initial response within seven days. Confirmed issues will
be coordinated privately until a fix and disclosure plan are ready.
